# Подготовка книги к публикации

Каталог приложения — `apps/web/src/data/catalog.json`, его серверная копия — `services/api/internal/httpapi/catalog.json`. [Библиографии](catalog-genres.md) содержат кандидатов: присутствие в них не добавляет книгу в приложение и не разрешает распространение файла. `kind: full` означает полноту текста, а не проверку прав; `rights` — описание, а не автоматический допуск к выпуску.

## Источник конкретного издания

Для каждой книги подготовить следующие сведения до добавления в публичную сборку:

| Материал | Что устанавливается | Что сохраняется |
| --- | --- | --- |
| Оригинал | Основание цифрового распространения в территории запуска; сроки и применимые специальные случаи либо разрешение правообладателя | Автор, название, дата публикации, основание и ссылка на подтверждение |
| Транскрипция и редакция | Из какого издания взят именно этот файл; какие комментарии, предисловия и другие самостоятельные материалы включены | Издание, том, страницы, постоянная ссылка/ревизия, состав и условия источника |
| Перевод | Кто перевёл текст, включая иностранные реплики и сноски; основание использования перевода отдельно от оригинала | Имя переводчика, издание, подтверждение условий либо документированный собственный перевод |
| Обложка | Соответствие печатному изданию и самостоятельное основание использования изображения | Автор оформления, если указан, издание/страница, источник, лицензия/основание, изменения, SHA-256 локального файла |

Доступность страницы, бесплатное скачивание и год смерти автора не подменяют проверку всего издания. Неизвестное происхождение оставляет материал на проверке. Недоступный источник требует повторной проверки или другого документированного источника, а не предположения о разрешении. Оценка для России не переносится автоматически на другие территории.

Для транскрипции с [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) сохраняются атрибуция, ссылка на условия и описание изменений; адаптация распространяется на тех же условиях. Лицензия не распространяет разрешение на чужие материалы, которые она не охватывает. Пример описания текста и отдельного изображения — [THIRD-PARTY.md](THIRD-PARTY.md).

Текст и обложка могут происходить из разных изданий: это указывается явно. Титульный лист сборника обозначается титульным листом; современное предисловие к оцифровке не принимается за страницу старого печатного издания. Для редакционных книг используются изображения соответствующих печатных изданий с подтверждёнными условиями, как предусмотрено в библиографии.

## Подготовка и проверка файлов

1. Сверить начало, конец, все главы и включённые материалы с документированным источником. Отделить неполный фрагмент от полного произведения. Проверить не только число глав, но и отсутствие пропущенных или повторённых участков.
2. Сохранить текст с устойчивыми chapter/paragraph IDs. Импорт простого EPUB описан в [README](../README.md#импорт-тестового-epub); `--rights-basis` записывает основание, но импортёр всегда возвращает `rights_status: pending` и не публикует книгу.
3. При изменении существующего текста подготовить новую версию и обновить связанные данные API по [архитектуре](ARCHITECTURE.md). Не заменять файл старой версии незаметно для сохранённых позиций и закладок.
4. Обновить manifest и API seed, индекс `services/api/internal/httpapi/bookmark-locations.json`, локальную обложку и сведения об источниках. Проверить нужную миграцию метаданных издания. URL лицензии и источников должны быть доступны из карточки книги.
5. Выполнить проверки ниже и открыть книгу в браузере: описание/атрибуция, обложка, первая и последняя глава, переходы, скачивание и восстановление позиции. Проверка новой редакционной книги не заменяется тестовой историей.

```sh
node scripts/check-content.mjs
npm run build
```

Первая команда сверяет размеры и SHA-256 текстов, версии, уникальность непустых абзацев, индекс locators и совпадение web/API manifest. Вторая проверяет TypeScript и сборку PWA. Ни одна из них не проверяет права, доступность внешних источников или полноту произведения по первоисточнику. Отсутствие автоматической ошибки не разрешает публикацию.

Перед выпуском отдельно проверить состав `apps/web/public`: он копируется в сборку, поэтому скрытие карточки из каталога само по себе не исключает файл книги или обложки из публичного доступа. Удаление издания из выпуска также требует учёта ссылок на него в личных данных; удалять пользовательские записи ради очистки каталога нельзя.

Внутренние решения о допуске конкретных книг и результаты приёмки остаются в локальных документах; в репозиторий входят происхождение используемых материалов, лицензионные уведомления и воспроизводимые инструкции.
